# OTA updates

Signed auto-updates via `tauri-plugin-updater`; the trust anchor is a minisign keypair, not Apple.

`src/lib/updater.js` wraps `@tauri-apps/plugin-updater` (check, download, relaunch via `plugin-process`) and is inert unless `import.meta.env.PROD`, so `tauri dev` never reports a bogus result. `useUiStore` owns the lifecycle (`updateCheck.phase`: idle/checking/current/available/downloading/installing/error) and the `checkForUpdates({ silent })` / `installUpdate` actions; `TitleBar` renders that state next to the theme toggle, and a silent check runs once three seconds after launch. The manual trigger is the macOS app menu item `check_updates`, inserted at index 1 of Tauri's default app submenu in `lib.rs` (About, Check for Updates…, separator, Services…) since replacing the default menu means re-declaring Edit/Window/Help by hand. It emits `menu:check-updates`, which `App.jsx` forwards to the store. Non-macOS has no manual trigger, only the launch check.

**The keypair is the whole security model.** `plugins.updater.pubkey` in `tauri.conf.json` is baked into every install, so whoever holds the private key can push executable code to all users. Losing it locks out every existing install permanently; replacing it requires shipping a release signed with the *old* key whose config trusts the new one. The key is passwordless, but `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` must still be set (empty) — when unset the CLI prompts, which blocks a non-interactive CI step.

Releases: `release.yml` signs via `TAURI_SIGNING_PRIVATE_KEY` and must publish (`releaseDraft: false`), because the endpoint is `releases/latest/download/latest.json` and that skips drafts. `createUpdaterArtifacts` emits the artifact plus `.sig` per platform, and `tauri-action` merges one `latest.json` across the matrix. `bundle.macOS.signingIdentity: "-"` is ad-hoc signing: free, and it avoids "app is damaged" on Apple Silicon. Notarization (paid Apple account) is deliberately still out, so the first install of a downloaded build remains a Gatekeeper hurdle.

Testing the whole flow without cutting a tag: build with `npx tauri build --config /tmp/ota-local.json`, where that file overrides `plugins.updater` with a `http://localhost:8765/latest.json` endpoint and `dangerousInsecureTransportProtocol: true` (never commit that flag), serve a hand-written manifest (`version`, `notes`, `pub_date`, `platforms["darwin-aarch64"] = { url, signature }`, signature being the `.sig` file's contents), and bump only `tauri.conf.json`'s `version` for the target build — the updater compares the *bundle* version. Updates the app downloads arrive without the quarantine attribute, so Gatekeeper only bites on the first install.
