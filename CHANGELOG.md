# Changelog

## [1.3.0] - 2026-10-23

### Added
- Read-only Codebase mode: attach one or more project folders and the model can `read_file`, `search_code`, and `list_dir` inside them, bounded by a root guard and a per-run byte/call budget
- `@`-mention file references in the composer, resolved into per-turn context before the model replies
- Chat title search in the sidebar, with a clear button and `Escape` to reset
- Sidebar chats grouped by last activity (Recent, This week, Last week, Older)
- Slash-command palette for `/layman` and `/summarise`, expanded at send time so the chat bubble keeps the short command
- Per-chat web search toggle, remembered per chat and inherited by side chats from their parent pane
- Model reasoning (`think`) is persisted with the message and shown in a collapsible block after a reload
- Agent log (Settings → Agent log) writing structured JSONL runs to the app data directory
- Native macOS window frame (traffic lights, rounded corners native to a titled window) via a platform config
- Codebase mode sizes `num_ctx` from the model's real context window, raising it only for cloud models
- `search_code` results and `list_dir` listings carry file sizes so the model pages large files instead of reading them whole

### Fixed
- A non-2xx Ollama response now emits `ollama://error` instead of an empty `ollama://done` (401/403/429 get a usage-limit message)
- Streamed responses no longer lose a chunk that ends mid-codepoint, which could drop a JSON line and splice two objects together
- Switching sessions or starting a new chat mid-run now stops the run instead of writing the new chat's messages into the old session
- Project folders attached from the main pane are persisted to the session (the pane was rendered without its `sessionId`)
- Chat panes stay mounted behind the settings page, so scroll positions survive opening and closing settings
- Single-dollar inline math (e.g. `$2^n$`) renders while bare currency (`$40`) stays literal
- Markdown links are legible on dark surfaces

## [1.2.0] - 2026-09-06

### Added
- Clickable follow-up subtopic chips at the end of an assistant answer; clicking one sends it as the next message in the current pane. Generated by a dedicated one-shot model call after the answer (transient — not persisted)
- Tool calls in a round now run in parallel (capped at 3) so a batch of web searches completes in the time of the slowest, not the sum
- Per-response search budget (15 `web_search`/`web_fetch` calls, 0 = unlimited) bounds total web activity; once hit the model answers from what it gathered
- Copy button on markdown code blocks
- Chat export/import to a compressed `.lumabackup` file (chat data only — no settings or API keys)
- Side-chat tabs nest as expandable rows showing the branch tree, with the first question as the tab tooltip

### Fixed
- Table cell text no longer overflows into neighboring columns (`overflow-wrap: break-word`)
- Malformed tool-call JSON arguments are surfaced to the model as a descriptive error instead of silently running the tool with empty args
- ROADMAP.md no longer describes the app as Electron (corrected to Tauri throughout)

## [1.1.0] - 2026-07-15

### Added
- Resizable sidebar with hover-to-expand titles
- Full URL tooltip on chat link hover
- Stop button now actually cancels `ollama_chat_stream` mid-stream instead of draining the response after Stop is pressed

### Fixed
- Currency dollar signs (e.g. `$40`, `$0.40`) no longer misparsed as math delimiters, which previously garbled pricing text in tables
- Math rendering switched to Temml (from KaTeX/MathJax) for smaller bundle size
- Side panels lazy-loaded to reduce initial bundle size
- Dynamic imports for `@tauri-apps/api/core` standardized, eliminating Vite optimization warnings
- Input box auto-focuses when switching or deleting chats, and when a new side chat is created
- `save_messages` made atomic and skips rewriting unchanged rows via upsert
- Web fetch body capped at 2 MB with a linear tag-stripping fallback
- `useChatSession` uses narrow selectors to avoid re-rendering every `ChatPane`
- Database path now resolved via Tauri's `app_data_dir()`, with automatic migration from the legacy `luma.db` location
